# Snapmaker U1 WLED Firmware

Prebuilt WLED firmware for the Snapmaker U1 WLED Status Bridge.

For v1.2.0, use:

**Snapmaker_U1_WLED_v1.2.0_ESP32_Watchdog.bin**

Install through:

**WLED → Config → Security & Updates → Update WLED**

Back up your WLED configuration and presets before updating.

No local compiling or USB programming is required for normal OTA installation.
