# Media Checklist

Use this checklist before the Snapmaker forum / Innovation Fund submission.

## Photos

- [ ] Hero photo: full U1 + PopStation setup with LEDs visible
- [ ] Idle: white breathing
- [ ] Heating: orange/red warm-up indication
- [ ] Printing: green breathing indication
- [ ] Hardware close-up: WLED controller and LED strip installation

## Video

- [ ] At least 40 seconds if also entering a community challenge that requires it
- [ ] Show the physical U1 and LED strip
- [ ] Show at least two status transitions
- [ ] Ideally show idle -> heating -> printing
- [ ] Include a brief view of the U1 screen or print starting so the LED transition is visibly tied to printer state
- [ ] End with the GitHub repository name/link in the post description

## Cover image

- [ ] Prepare a 640 x 360 cover image if required by the Innovation Fund form
- [ ] Use the finished U1 installation as the main subject
- [ ] Keep text minimal and readable
